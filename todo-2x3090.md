**2×3090 Docker setup**

**Changes made:**
1. `docker-compose.yml` — the `x-serve` anchor's GPU reservation changed `count: 1` → `count: 2`, so the serving container now sees both cards. 
2. `.env` — created (git-ignored, based on `.env.example`):
   - `SPEC=dflash2`, `PREFIX_CACHE=1` — the repo's recommended single-user speed profile; DFlash2 is the measured winner at every concurrency on 2×24 GB (issue #40).
   - `EXTRA_ARGS=--tensor-parallel-size 2` — the single-user launcher (`single-user/start_qwen.sh`) parses this out, auto-drops the single-card `KV_MEM` pin (it would strand ~16 GiB per worker at TP=2), and appends it to `vllm serve`, so the KV pool is sized from `GPU_UTIL` instead.
   - `VLLM_WSL2_ENABLE_PIN_MEMORY=1` kept from the template (no-op on native Linux).
   - `DFLASH_TOKENS` deliberately left at the default 7 — the one measured T=15 datapoint at TP=2 lost 27% at C1; a comment in the file says not to flip it.
